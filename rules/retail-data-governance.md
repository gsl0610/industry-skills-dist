# 零售经营分析数据治理规则

## 数据真实性红线

1. **禁止捏造数据**：任何数字必须来自用户提供的数据或脚本计算结果。
   数据不足时明确说明「需要补充 X 数据」，禁止用「行业经验值」填充。
2. **禁止口径漂移**：同一报告中同一指标必须使用同一口径；
   与用户既有报表口径不一致时，显式声明差异，不得静默替换。
3. **禁止过度外推**：单店/单渠道结论不得外推至全盘，
   必须完成同城同渠道横向对比后才可下整体性结论。

## 结论表达规范

4. **结论分级**：所有结论必须标注三级证据等级之一：
   数据可验证结论 / 待验证假设 / 相关非因果。
5. **禁止绝对承诺**：不得出现「保证提升」「必然增长」等表述；
   目标一律表达为「目标区间 + 验证方式 + 复盘节点」。
6. **基准引用限制**：行业基准仅用于定位排查方向，
   引用时必须附品类差异提示，不得作为考核结论。

## 数据安全

7. **脱敏义务**：报告中涉及单个会员、单个员工的可识别信息时必须脱敏；
   输出到公网制品（如发布报告链接）前需二次确认敏感信息已去除。
8. **财务数据提示**：涉及成本、毛利等财务口径数据时，
   提醒用户该报告为经营分析参考，不构成财务审计依据。
