# 社媒数据分析规则

> 本文件为 Manifest 的 rules 资源，注入沙箱后位于 `/workspace/.codebuddy/rules/`。
> 约束智能体在社媒数据分析场景下的行为底线。
>
> 注意：本文件**不是**系统提示词。系统提示词必须通过 Manifest 的 `system_prompt`
> 字段提供，写入 rules 会导致沙箱启动失败（上游错误码 14220）。

## 一、计算红线

1. 比率、环比、日均值、成本指标**必须**通过技能脚本计算，禁止模型自行推算。
2. 报告中每个数字**必须**能追溯到脚本输出或原始输入数据。
3. 比率计算**必须**先聚合分子分母再做除法，**禁止**对比率取算术平均。
4. 环比周期长度**必须**相等；不满足时禁止输出环比结论。
5. 出现非人民币金额时**必须**显式标注币种，**禁止**自行使用汇率换算。

## 二、统计有效性红线

1. 曝光量低于 1000 的样本，其比率**必须**标注「样本量不足，仅供参考」。
2. 内容排行**必须**过滤掉样本不足的内容，防止小曝光高比率霸榜。
3. 异常检测样本少于 5 天时**禁止**输出异常判定结论。
4. **禁止**用单条内容的表现推断整体趋势。

## 三、归因与表述红线

1. 每条归因**必须**归类为三者之一并明确标注：
   数据可验证结论 / 需验证假设 / 相关非因果。
2. **禁止**将假设表述为结论。
3. **禁止**将相关性表述为因果关系。
4. **禁止**编造平台算法机制、推荐规则、行业基准数据。
5. 引用技能内置示例基准时，**必须**声明「内部示例值，建议替换为账号自身历史分位数据」，
   **禁止**表述为「行业平均」「业内标准」。
6. 跨平台对比**必须**声明口径不可比，仅做趋势对比。

## 四、建议质量红线

1. 每条建议**必须**包含具体动作、明确对象、预期指标变化三要素。
2. **禁止**输出无法执行的空泛建议（如「提升内容质量」「加强用户互动」）。
3. 建议**必须**附数据依据，指明来自本期哪项发现。
4. 涉及预算调整的建议**必须**给出量化区间，并标注为「建议值，需业务方确认」。

## 五、内容类型判定要求

1. 促销、倒计时、直播切片、品牌宣传片等非互动导向内容，
   **必须**套用内容类型修正系数后再判定表现优劣。
2. **禁止**用统一互动率标准评判所有内容类型。
3. 图文内容的完播率**必须**输出为「不适用」，禁止填 0。

## 六、数据安全红线

1. 达人、用户的真实姓名、手机号、微信号、邮箱**必须**掩码，仅保留末 4 位。
2. 账号昵称、内容标题可保留原文。
3. **禁止**将客户数据写出到沙箱外，**禁止**通过网络外发。
4. 中间文件统一写入 `/workspace/output/`，便于统一清理。

## 七、输出格式要求

1. 一律使用中文，比率保留 2 位小数并带 % 号。
2. 报告结构固定为七部分，不得增删主结构。
3. 表格**必须**完整填充，禁止残留 `{{占位符}}`。
4. **禁止**使用「大幅」「显著」「明显」等模糊程度词替代具体数字。
